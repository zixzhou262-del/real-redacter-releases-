# ReaL Redacter macOS Releases

这里仅发布 ReaL Redacter 的 macOS 版本。

软件支持 Word、Markdown 和 TXT 文档，可以识别金额、数字、百分比，也可以填写自定义敏感词。例如在自定义区域输入“苹果”，文档中出现的“苹果”都会被替换成可恢复的脱敏标记。

所有处理都在本机完成，不上传文件、不调用云端 API，也不需要注册账号。
